# Launcher artwork

`hero.png` and `brand.png` are original artwork generated for this fork with
OpenAI image generation, following the repository owner's launcher references.
The originals are retained here. They contain no downloaded game resources.
The application decodes and sizes them for the launcher at runtime.

Hero: voxel lake and forest at sunset, with dark space on the left for headings.
Brand: isolated purple crystal cube with a transparent background.
